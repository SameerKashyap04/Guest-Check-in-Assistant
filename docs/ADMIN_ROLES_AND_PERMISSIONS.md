# Admin Roles & Permissions Specification

## Roles

1. **Super Admin**:
   - Full access to all revenue, subscription overrides, plan configurations, and user management.
   - Ability to grant/revoke admin access.

2. **Support Admin**:
   - Access to user and property directories for customer troubleshooting.
   - Ability to extend trials or grant manual subscription credits.
   - Masked PII view by default.

3. **Read-Only / Auditor**:
   - Access to revenue metrics, usage analytics, and audit logs.
   - No write permissions.
