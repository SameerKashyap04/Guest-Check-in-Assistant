# StayMate — Admin Control Panel

> ⚠️ **RESTRICTED SYSTEM ACCESS**: This application is exclusively for the **Platform Operations & Developer Team** managing the StayMate SaaS Platform.
>
> **NOT FOR PROPERTY OWNERS**: Hotel, homestay, guesthouse, resort, and property operators perform guest check-ins, ID scanning, and room management in the main **StayMate Mobile & Web application**.

---

## Developer Company Admin Capabilities

- 📊 **MRR & ARR Financial Operations**: Monitor revenue, active subscription tiers, and pricing plan performance.
- 🏢 **Property & User Oversight**: Oversee onboarded homestays, room capacities, and property owner accounts.
- 💳 **Devify Pay Gateway Management**: Manage Devify API keys, HMAC webhook verification secrets, and order ledgers.
- 🔒 **PII Protection Control**: Centralized Aadhaar and guest ID document masking/unmasking toggle for privacy compliance.

---
